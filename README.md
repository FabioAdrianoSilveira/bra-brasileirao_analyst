# Brasileirão Analyst

## :clipboard: Descrição do projeto

Brasileirão Analyst é um aplicativo web que têm como objetivo ajudar os usuários a acompanhar as principais estatísticas dos jogadores de seus clubes para que façam análises de desempenho dos atletas, além de permitir que vejam as chances de vitória em embates com outros participantes do Campeonato Brasileiro de Futebol Série A.
